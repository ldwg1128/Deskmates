# DeskMates

Windows 바탕화면 친구 **DeskMates**입니다. **리베르타 (Liberta)**와 **Zenith**를 지원하며, 처음 실행할 때는 리베르타가 나타납니다. 우클릭으로 캐릭터를 전환할 수 있습니다.

`dist\DeskMates.exe`를 더블 클릭하면 바로 실행됩니다. 실행 파일 하나만 있으면 되며 Python 설치가 필요 없습니다.

- 드래그: 캐릭터가 커서 아래에 거꾸로 매달려 흔들립니다. 놓으면 몸을 접고 펼치는 두 중간 포즈로 반바퀴 회전하며, 중력으로 화면 아래까지 내려와 착지한 뒤 일어납니다. 착지한 위치 주변을 새 산책 범위로 삼습니다. 동작 그림의 눈은 원본과 같은 보라색 계열입니다.
- 한 번 클릭: 인사하거나 점프합니다.
- 우클릭 → **캐릭터 크기**: 80~320px 프리셋 또는 **직접 입력**으로 64~400px 높이를 정합니다. 가로·세로에 동일한 배율을 적용하여 원본 신체 비율을 유지합니다.
- 우클릭 → **캐릭터 전환** → **리베르타 (Liberta) / Zenith**: 바로 캐릭터를 바꿉니다. 크기와 행동 설정은 유지되며, 선택한 캐릭터는 다음 실행에도 복원됩니다.
- 우클릭 → **행동 설정…**: 산책 범위, 걷는 속도, 제자리 모드, 일시정지, 마우스 통과를 하나의 창에서 설정하고 **저장**으로 적용합니다. 두 캐릭터가 같은 설정을 사용합니다. **취소**하면 입력한 설정을 적용하지 않습니다.
- 행동 설정의 **제자리 모드 (걷기만 멈추기)**: 산책만 멈추고 현재 위치에서 인사·점프·고개 숙이기·커서 바라보기 등을 계속합니다. 체크를 해제하면 다시 돌아다닙니다. 드래그 이동과 착지도 계속 사용할 수 있습니다.
- 행동 설정의 **잠시 멈추기**: 자동 동작과 이동을 멈추거나 다시 시작합니다. 가까운 커서 바라보기와 드래그·착지는 계속 사용할 수 있습니다.
- 행동 설정의 **이 위치를 산책 중심으로 / 화면 아래로 데려오기**: 버튼을 누르면 즉시 위치를 적용합니다.
- 우클릭 → **종료**: 프로그램을 종료합니다.
- 행동 설정의 **마우스 통과**를 켜면 캐릭터를 클릭할 수 없습니다. 작업 표시줄 알림 영역의 펫 아이콘을 우클릭하면 캐릭터를 전환하거나 설정을 바꾸고 종료할 수 있습니다. 숨겨진 아이콘 펼치기(∧) 안에 있을 수 있습니다.
- 트레이 아이콘 더블 클릭 또는 행동 설정의 **화면 아래로 데려오기**: 현재 커서가 있는 모니터 아래로 데려옵니다.

커서가 캐릭터 몸 주변에 가까워지면 이동과 일반 동작을 멈추고 계속 커서 방향을 바라봅니다. 커서가 멀어지면 다시 산책합니다. 멀리 있어도 가끔 커서를 바라보고 인사·점프·고개 숙이기 등의 행동을 합니다. 드래그와 착지 중에는 해당 동작을 끝까지 이어갑니다. 작업 표시줄을 제외한 화면 안에서 움직이며, 여러 모니터 사이에서는 드래그로 옮길 수 있습니다. 같은 프로그램을 중복 실행해도 캐릭터가 추가로 생기지 않습니다.

선택한 캐릭터, 크기, 산책 중심·범위, 속도, 제자리 모드, 일시정지, 마우스 통과 설정은 `%LOCALAPPDATA%\DeskMates\DeskMates\settings.json`에 저장됩니다. 기존 설정 파일도 읽으며 캐릭터 선택이 없으면 리베르타로 시작합니다. 자동 시작은 등록하지 않습니다.

## 소스로 실행 / 빌드

```powershell
python -m pip install -r requirements.txt
python desktop_pet.py
```

실행 파일을 다시 빌드하려면 `python -m pip install pyinstaller` 후 `powershell -ExecutionPolicy Bypass -File .\build.ps1`을 실행하세요. 빌드 전에 실행 중인 DeskMates를 종료하세요.

리베르타의 기본 동작·16방향 시선은 `assets\liberta-spritesheet.png`, 매달리기·회전·착지 포즈는 `assets\liberta-motion.png`에 포함된 제공 이미지에서 가져옵니다. 캐릭터별 고정 자르기와 동일한 배율을 사용해 비율을 유지합니다. Zenith 원본은 `assets\spritesheet.png`와 `assets\drag-landing-v3.png`입니다. 캐릭터 구성은 `desktop_pet.py`의 `CHARACTERS`에서 관리합니다.

검증은 `python verify_pet.py`로 실행합니다. 두 캐릭터의 렌더링, 이동, 드래그·착지, 메뉴 전환, 설정 저장·복원을 확인합니다. `python preview_motion.py --character liberta`로 낙하 애니메이션 미리보기를 생성할 수 있습니다.

투명한 테두리 없는 창 구현은 [Qt 공식 QWidget 문서](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QWidget.html)를 따릅니다.
