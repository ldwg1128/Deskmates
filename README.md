# DeskMates

Windows 바탕화면 친구 **DeskMates**입니다. **리베르타 (Liberta)**, **제니스 (Zenith)**, **세이르 (Seir)**를 지원하며, 처음 실행할 때는 리베르타가 나타납니다. 우클릭으로 캐릭터를 전환할 수 있습니다.

`dist\DeskMates.exe`를 더블 클릭하면 바로 실행됩니다. 실행 파일 하나만 있으면 되며 Python 설치가 필요 없습니다.

- 드래그: 캐릭터가 커서 아래에 거꾸로 매달려 흔들립니다. 놓으면 몸을 접고 펼치는 두 중간 포즈로 반바퀴 회전하며, 중력으로 화면 아래까지 내려와 착지한 뒤 일어납니다. 착지한 위치 주변을 새 산책 범위로 삼습니다. 동작 그림의 눈은 원본과 같은 보라색 계열입니다.
- 한 번 클릭: 인사하거나 점프합니다.
- **창에 앉기·매달리기**: 캐릭터를 일반 프로그램 창 상단 가까이에 끌어 놓으면 잠시 앉았다가 뛰어내려 착지합니다. 창의 왼쪽·오른쪽 세로 가장자리에 놓으면 **창을 바라보는 옆모습**으로 매달려 다리를 버둥거리다가 떨어집니다. 손은 같은 위치에 고정되고 몸은 창 바깥쪽에 놓입니다. 창을 옮기면 함께 이동하며, 창을 닫거나 최소화하면 떨어집니다. 끝나면 기존 산책 방식·방향으로 복귀합니다. 화면 밖으로 몸이 잘리는 위치에는 붙지 않습니다.
- **잠들기**: 캐릭터와 **30분** 동안 상호작용하지 않으면 화면 아래쪽 구석으로 가서 잠듭니다. 만지거나 가까이 커서를 움직이면 귀찮아하는 표정과 대사로 깨어납니다. 제자리 모드에서는 현재 위치에서 자고, 테두리 산책에서는 선택한 방향으로 이동합니다. **행동 설정 → 고급 → 추가 행동**에서 끄거나 대기 시간을 5/10/30분으로 고릅니다.
- **커서 잡기**: 일반 산책 중 가까운 커서를 허리 높이에 잠시 두면 다가가 손으로 잡는 동작을 합니다. 커서를 멀리 옮기면 추적을 멈춥니다. 실제 마우스 커서를 가두거나 움직이지 않습니다.
- **공 놀이**: 우클릭 → **공 꺼내기**로 별도의 공을 표시합니다. 공을 끌어서 캐릭터 발 근처에 놓으면 일반 산책 중 다가가 차고, 날아간 공은 사라집니다. **공 치우기**로 직접 숨길 수도 있습니다.
- **몰래 간식 먹기**: 배고플 때 드물게 숨겨 둔 간식을 꺼내 먹습니다. 끝나기 전에 취소하면 스택이 늘지 않으며, 먹으면 포만감이 1스택 늘어납니다. 창 상호작용·커서 잡기·희귀 행동도 **고급 → 추가 행동**에서 켜고 끌 수 있습니다.
- **빵 주기**: 커서를 캐릭터 가까이에 약 0.7초 두면 머리 위에 작은 빵 버튼이 나타납니다. 버튼을 누르면 빵이 짧은 거리에서 떨어지고 캐릭터가 받아 한입 먹고, 씹은 뒤 만족하는 표정을 짓습니다. 일반 바탕화면 클릭은 먹이 주기로 처리하지 않습니다. 먹는 동안에는 이동을 멈추며 연속으로 빵을 쌓을 수 없습니다. 끝나면 원래 행동으로 돌아갑니다.
- **배고픔·포만감**: 먹기를 마친 빵은 캐릭터별로 최대 5스택까지 쌓입니다. **0개는 배고픔 / 1~2개는 보통 / 3~4개는 배부름 / 5개는 너무 배부름**입니다. 0개일 때는 배를 감싸고 문지르는 전용 동작과 “꼬르륵… 배고파.” 말풍선이 나옵니다. 처음에는 6~10초, 이후에는 12~20초의 대기 간격을 두며 현재 동작을 마친 뒤 표현합니다. 커서 바라보기·드래그·먹기 중에는 해당 상호작용을 우선합니다. 빵 주기 옵션을 끄면 배고픔 동작도 끕니다. 일시정지 중에는 자동 배고픔 동작도 멈춥니다.
- **배부를 때 빵 주기**: 5스택이면 빵을 받아 손에 든 채 고개를 좌우로 젓고, “너무 배불러… 이제 못 먹겠어!” 등의 대사로 거절합니다. 마지막에 빵을 내미는 자세는 약 1.5초간 유지합니다. 계속 주면 다른 대사도 나옵니다. 거절한 빵과 먹기 도중 취소한 빵은 스택에 추가하지 않습니다.
- **소화**: 스택이 생긴 시점부터 **1분 / 3분 / 5분마다 1개씩** 줄어들도록 **행동 설정 → 빵 주기 → 스택 감소 간격**에서 선택합니다. 기본값은 기존과 같은 1분이며 모든 캐릭터에 공통 적용됩니다. 간격을 바꿔도 현재 소화 주기의 진행 비율은 유지합니다. 새로 먹거나 거절해도 소화 주기는 밀리지 않습니다. 5→4스택이 되면 다시 먹을 수 있습니다. 캐릭터별 스택·소화 시각을 저장하며 앱을 꺼 둔 시간도 반영합니다. 우클릭 메뉴와 빵 버튼 툴팁에서 현재 상태·개수를 확인할 수 있습니다.
- 행동 설정의 **빵 주기 버튼 표시**: **빵 주기** 그룹에 있으며 기본값은 켜짐이고 두 캐릭터에 공통 적용됩니다. 마우스 통과 중에는 버튼이 나타나지 않습니다. 제자리 모드·일시정지 중에도 직접 빵을 줄 수 있습니다. 테두리 산책 중에는 벽·천장의 자세와 진행 위치를 유지해 먹고 선택한 방향으로 다시 걷습니다. 코너 점프·드래그·착지 중에는 버튼을 숨깁니다.
- 우클릭 → **캐릭터 크기**: 80~320px 프리셋을 고릅니다. 원하는 높이는 **행동 설정 → 고급**에서 64~400px로 직접 입력할 수 있습니다. 가로·세로에 동일한 배율을 적용하여 원본 신체 비율을 유지합니다.
- 우클릭 → **캐릭터 전환** → **리베르타 (Liberta) / 제니스 (Zenith) / 세이르 (Seir)**: 바로 캐릭터를 바꿉니다. 크기와 행동 설정은 유지되며, 선택한 캐릭터는 다음 실행에도 복원됩니다.
- 우클릭 → **행동 설정…**: **캐릭터 크기**를 첫 번째로 표시합니다. **산책 방식** 그룹에서 **일반 산책 / 모니터 테두리 산책** 라디오 버튼으로 선택합니다. 일반 산책에서는 **산책 범위**를, 테두리 산책에서는 **도는 방향**과 테두리 산책 설명을 표시합니다. **걷기 설정** 그룹에는 걷는 속도와 제자리 모드, **빵 주기** 그룹에는 빵 주기 버튼 표시와 스택 감소 간격을 모았습니다. 크기·걷기·일시정지·빵 주기 설정은 공통입니다. 범위는 **좁게 / 보통 / 넓게 / 아주 넓게**, 속도는 **느림 / 보통 / 빠름** 중에서 고릅니다. 기본 목록에는 픽셀 수치를 표시하지 않습니다. 창 아래쪽 **고급**을 펼치면 크기·범위·속도를 픽셀 단위로 직접 입력하고 윈도우 기본 도구 표시도 설정할 수 있습니다. 고급에서도 산책 범위는 일반 산책일 때만 나타납니다. 기존에 직접 입력한 값은 **사용자 지정**으로 유지하며 정확한 수치는 고급에서 확인합니다. **저장**으로 적용하며 두 캐릭터가 같은 설정을 사용합니다. **취소**하면 입력한 설정을 적용하지 않습니다.
- 행동 설정의 **산책 방식 → 모니터 테두리 산책**: 현재 모니터의 작업 영역 테두리를 따라 바닥·벽·천장을 걷습니다. **시계 방향 / 반시계 방향**을 선택하면 같은 방향으로 계속 돌며, 잠시 멈춰 인사·생각하기 등의 제자리 동작을 한 뒤 다시 걷습니다. 네 코너에서는 전용 도약·공중·착지 포즈로 점프하며 몸이 90도 회전합니다. 점프를 마친 뒤 쉬거나 커서를 바라봅니다. 테두리 산책에는 산책 범위 대신 모니터 전체 테두리를 사용합니다.
- 테두리 산책 중 드래그를 놓으면 해당 모니터의 가장 가까운 테두리에 붙습니다. **일반 산책**으로 바꾸면 기존 이동·중력·착지 방식으로 돌아갑니다. 작업 표시줄은 작업 영역에서 제외합니다.
- 행동 설정의 **제자리 모드 (걷기만 멈추기)**: 산책만 멈추고 현재 위치에서 인사·점프·고개 숙이기·커서 바라보기 등을 계속합니다. 체크를 해제하면 다시 돌아다닙니다. 드래그 이동과 착지도 계속 사용할 수 있습니다.
- 행동 설정의 **잠시 멈추기**: 자동 동작과 이동을 멈추거나 다시 시작합니다. 가까운 커서 바라보기와 드래그·착지는 계속 사용할 수 있습니다.
- 행동 설정 → **고급 → 윈도우 기본 도구 표시**: 켜고 저장하면 캐릭터와 트레이의 우클릭 메뉴 상단에 **메모장 / 그림판 / 계산기**가 나타납니다. 항목을 클릭하면 해당 Windows 도구를 실행합니다. 기본값은 꺼짐이며 다음 실행에도 선택을 유지합니다.
- **위치·산책 중심 변경**: 캐릭터를 마우스로 끌어서 옮깁니다. 일반 산책은 놓은 뒤 착지한 위치를 산책 중심으로 삼고, 테두리 산책은 놓은 위치에서 가까운 테두리에 붙습니다.
- 우클릭 → **종료**: 프로그램을 종료합니다.
- 우클릭 메뉴의 **종료 바로 위 → 마우스 통과**를 켜면 캐릭터를 클릭할 수 없습니다. 작업 표시줄 알림 영역의 펫 아이콘을 우클릭하면 같은 항목에서 마우스 통과를 끄거나 캐릭터·설정을 바꾸고 종료할 수 있습니다. 숨겨진 아이콘 펼치기(∧) 안에 있을 수 있습니다.
- 트레이 아이콘 더블 클릭: 현재 커서가 있는 모니터 아래로 데려옵니다.

커서가 캐릭터 몸 주변에 가까워지면 이동과 일반 동작을 멈추고 계속 커서 방향을 바라봅니다. 커서가 멀어지면 다시 산책합니다. 멀리 있어도 가끔 커서를 바라보고 인사·점프·고개 숙이기 등의 행동을 합니다. 드래그와 착지 중에는 해당 동작을 끝까지 이어갑니다. 작업 표시줄을 제외한 화면 안에서 움직이며, 여러 모니터 사이에서는 드래그로 옮길 수 있습니다. 같은 프로그램을 중복 실행해도 캐릭터가 추가로 생기지 않습니다.

선택한 캐릭터, 크기, 산책 중심·범위, 속도, 산책 방식, 테두리 방향·진행 위치, 제자리 모드, 일시정지, 마우스 통과, 윈도우 기본 도구 표시, 빵 주기 버튼 표시, 스택 감소 간격, 캐릭터별 빵 스택과 소화 시각은 `%LOCALAPPDATA%\DeskMates\DeskMates\settings.json`에 저장됩니다. 기존 설정 파일도 읽으며 캐릭터 선택이 없으면 리베르타로 시작합니다. 자동 시작은 등록하지 않습니다.

## 소스로 실행 / 빌드

세이르는 제공된 정면·측면·표정·SD 이미지를 분석해 제작했습니다. 올리브빛 긴 머리·보라색 리본·자주빛 눈·남색 정장·분홍 명찰·검은 가방을 유지하고, 현재 **22개 행동 / 110프레임**을 연결했습니다. [제작 기록과 이미지·프롬프트](docs/seir-character.md), `characters/seir/character.json`에서 확인할 수 있습니다. 세이르가 포함된 최신 단일 실행 파일은 **`dist/DeskMates.exe`**입니다.

추가 행동의 상태 전환·이미지 출처·검증 방법은 [데스크톱 상호작용 안내](docs/desktop-interactions.md)에 정리했습니다. 이전 기능 단계의 별도 빌드는 `artifacts/desktop-interactions/DeskMates.exe`입니다.

```powershell
python -m pip install -r requirements.txt
python desktop_pet.py
```

실행 파일을 다시 빌드하려면 `python -m pip install pyinstaller` 후 `powershell -ExecutionPolicy Bypass -File .\build.ps1`을 실행하세요. 빌드 전에 실행 중인 DeskMates를 종료하세요.

빌드는 등록된 캐릭터의 JSON과 실제 연결된 이미지·기준 이미지를 모아 넣습니다. 제작 원본·프롬프트·템플릿은 저장소에 보존하며 실행 파일에 불필요하게 중복 포함하지 않습니다. 단일 EXE 실행에는 별도 캐릭터 폴더나 이미지 생성 도구가 필요 없습니다.

리베르타의 기본 동작·16방향 시선은 `assets\liberta-spritesheet.png`, 매달리기·회전·착지 포즈는 `assets\liberta-motion.png`에 포함된 제공 이미지에서 가져옵니다. 캐릭터별 고정 자르기와 동일한 배율을 사용해 비율을 유지합니다. 제니스 (Zenith)는 이동 시 머리 비율을 보정한 `assets\zenith-spritesheet-v2.png`와 대기 자세에 맞춰 색감·비율을 보정한 낙하 시트 `assets\zenith-motion-v4.png`를 사용합니다. 대기·인사·시선 프레임은 원본을 유지합니다. 캐릭터 구성은 `characters/{id}/character.json`, 공통 행동 규격은 `animation_catalog.json`에서 관리하며 신규 캐릭터 추가에 게임 핵심 코드 수정이 필요 없습니다.

리베르타는 `assets\liberta-motion.png`의 옆모습 달리기 8프레임으로 수평 산책합니다. 왼쪽 이동은 좌우 반전한 프레임을 사용하며, 이동 거리와 캐릭터 크기에 맞춰 발 동작을 진행합니다. 공통 배율과 기준선을 사용해 이동 중 크기와 위치가 불필요하게 흔들리지 않도록 합니다.

검증은 `python verify_pet.py`와 `python verify_edge.py`로 실행합니다. 두 캐릭터의 렌더링, 이동, 드래그·착지, 메뉴 전환, 설정 저장·복원을 확인하며 테두리 방향 유지, 휴식, 코너 점프, 화면 안의 표시도 검증합니다. `python preview_motion.py --character liberta`로 낙하 애니메이션 미리보기를, `python preview_edge.py --character zenith --direction clockwise`로 테두리 산책 미리보기를 생성할 수 있습니다.

코너 점프의 추가 4포즈 이미지는 `assets\zenith-corner-jump.png`와 `assets\liberta-corner-jump.png`이며, 기본 캐릭터를 참고해 내장 이미지 생성 도구로 제작했습니다. 프롬프트는 `assets\corner-jump-prompts.txt`에 기록했습니다.

`python verify_tools.py`로 윈도우 기본 도구 표시 토글, 메뉴 순서, 실행 연결, 설정 저장·취소를 검증합니다.

`python verify_settings.py`로 산책 라디오 버튼, 방식별 항목 표시, 숫자를 숨긴 프리셋, 고급 항목, 사용자 지정 값 보존, 마우스 통과 메뉴·트레이 복구, 저장·취소를 검증합니다. 일반·테두리 산책과 각각의 고급 창 미리보기를 `artifacts/settings-*.png`로 저장합니다.

빵과 두 캐릭터의 먹기 4포즈는 내장 이미지 생성 도구로 만든 `assets\bread.png`, `assets\liberta-feeding.png`, `assets\zenith-feeding.png`를 사용합니다. 생성 프롬프트는 `assets\feeding-prompts.txt`에 기록했습니다. 먹기 프레임은 같은 배율을 사용하면서 양발 중심과 바닥선을 대기 자세에 맞춰 정렬합니다. 빵을 올려다보는 자세도 같은 기준을 사용해 프레임 전환 시 좌우로 어긋나는 것을 줄입니다. `python verify_feeding.py`로 버튼 대기 시간·클릭, 먹기 과정, 연속 클릭 방지, 설정 저장·취소, 테두리 산책 복귀, 드래그·캐릭터 전환 시 정리를 검증하며, 64·160·320·400px와 네 테두리 자세에서 발 위치도 비교합니다.

테두리 회전 시 이전 프레임이 겹쳐 남지 않도록 프레임별 창 마스크를 사용하지 않고, [Qt의 `CompositionMode_Source`](https://doc.qt.io/qt-6/qpainter.html#CompositionMode-enum)로 투명 픽셀까지 교체합니다. 투명 영역의 클릭 통과는 [Windows 레이어 창의 알파 판정](https://learn.microsoft.com/en-us/windows/win32/winmsg/window-features#layered-windows)을 사용합니다. Windows에서 `python verify_rendering.py`를 실행하면 두 캐릭터의 160·320·400px, 양방향·네 코너를 포함한 1,152프레임을 실제 창 버퍼와 픽셀 단위로 비교하고 클릭 통과도 검증합니다.

투명한 테두리 없는 창 구현은 [Qt 공식 QWidget 문서](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QWidget.html)를 따릅니다.

## 새 캐릭터 제작과 자동 생성

정면·측면·후면 참고 이미지에서 디자인 명세를 만들고 현재 전체 행동의 프롬프트·배치 가이드·투명 템플릿을 생성할 수 있습니다. 선택적 이미지/비전 API 연결 시 생성 → 프레임별 검사 → 실패 슬롯만 재생성 → 검토 → 등록을 수행합니다. API가 없으면 외부 이미지 가져오기로 같은 흐름을 사용합니다. 재시도 횟수와 비용 예약 한도는 재실행 후에도 유지합니다. 기존 두 캐릭터의 PNG와 재생 결과는 보존했습니다.

```powershell
python -m pip install -r requirements-tools.txt
python character_tool.py create characters/my_pet --id my_pet --name "새 친구" --reference "front=C:/images/front.png" --reference "side=C:/images/side.png"
python character_tool.py auto characters/my_pet
# 실제 API: requirements-openai.txt 설치, provider.example.json 복사/설정 후
python character_tool.py auto characters/my_pet --config provider.local.json --max-retries 2 --cost-limit 5
```

자세한 명령과 비용 한도의 의미는 [캐릭터 제작 안내](docs/character-authoring.md)를 참조하세요. [기존 행동 분석](docs/animation-behavior-analysis.md), [스킬 설계 조사와 단계별 계획](docs/character-system-plan.md), [검증 결과](docs/regression-results.md)도 제공합니다. `python examples/demo_autogen.py`로 유료 호출 없이 더미 전체 생성과 고장 프레임의 선택적 재생성을 재현합니다. 결과와 GIF는 `artifacts/autogen-demo`에 저장합니다.

배고픔·포만감은 `appetite.py`에서 관리합니다. 배고픔 4포즈는 `assets\liberta-hungry.png`, `assets\zenith-hungry.png`, 빵을 받아들고 거절하는 4포즈는 `assets\liberta-refusal.png`, `assets\zenith-refusal.png`입니다. 내장 이미지 생성 도구로 제작했으며 프롬프트는 `assets\appetite-prompts.txt`에 기록했습니다. 기존 먹기 동작처럼 배율을 고정하고 대기 자세의 양발 중심·바닥선에 맞춥니다. `python verify_appetite.py`로 스택 단계, 5스택 거절, 소화·재급여, 캐릭터별 저장, 앱 종료 중 경과 시간, 벽·천장 동작과 말풍선 위치를 검증합니다.
