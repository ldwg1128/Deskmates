# 공 놀이 물리와 애니메이션

공은 별도의 투명 Qt 창이다. 지름은 캐릭터 설정 높이의 약20%, 충돌 반경은 그 절반이다. 픽셀 반올림 오차는0.5px 이내이며 바깥2px는 투명 여백이다. 크기를 바꾸면 공의 그림·충돌·드래그 경계·바닥 접촉점을 함께 갱신한다. QPainter의 방사형 그라데이션, 하이라이트, 가장자리 음영과 회전하는 패널로 입체감을 표현한다.

`ball_physics.py`는 Qt 없이 실행하는 결정적 물리 모델이다. 최대1/240초 단위로 적분하고 중력·바닥 반발·벽 충돌·마찰을 적용한다. 손에서 놓은 공은 정지 속도에서 낙하하며 에너지가 줄어드는 반동 후 바닥에 멈춘다. 발로 찬 공만0.9초 동안 날아가며 사라진다.

머리 충돌은 정상 자세의 머리 윗면을 공의 아랫면이 **하강 중 통과하는지** 확인한다. 빠르게 떨어져도 이전·현재 위치 사이의 교차를 검사한다. 한 번 놓을 때 한 번만 반응한다. 기존 먹기·드래그·착지·테두리·추가 행동은 중단하지 않는다. 일시정지·제자리 모드에서도 정상 자세라면 직접 떨어뜨린 공에 반응한다. 좌우를 무작위로 선택하고, 벽에 가까우면 공간이 있는 쪽을 선택한다. 캐릭터 크기와 남은 화면 공간으로 이동 거리를 제한하며 중력과 감쇠 반동을 거쳐 바닥에 멈춘다.

기존 헛발질은 산책 반경에 제한한 목표점에 도착하거나3초가 지나기만 하면 발차기로 전환하던 조건에서 발생했다. 이제 같은 모니터의 바닥에 멈춘 공에 화면 내에서 접근하고, 실제 접촉 거리에서만 찬다. 접근 제한 시간은 거리/속도로 계산한다. 공을 잡거나 옮기거나 숨기면 접근·준비 동작을 취소한다. 제자리·일시정지는 먼 공을 추적하지 않는다. 놀이 후 기존 산책 범위를 벗어났으면 순간 이동 없이 걸어서 복귀하며 산책 중심·방식·설정은 보존한다.

발차기는0.95초다. 시작12%와 마지막16%에는 원래 대기 그림을 같은 발 기준점에 그린다. 중간72%에는 준비→무릎 들기→발 뻗기→회복4포즈를 재생하며 `impact_frame`(기본2)의 시작에 공 속도를 적용한다. `contact_reach`는 기준 신체 높이에 대한 실제 발 끝의 수평 도달 비율로, 캐릭터별 그림에서 측정한다. 발 끝과 크기에 비례한 공의 반경이 겹쳐야 찰 수 있다. 새 그림은 동작별 공통 배율과 고정 지지 발로 배치해 몸 크기·바닥 위치의 급변을 줄였다. 일반 산책·대기 이미지는 변경하지 않았다.

`artwork/ball`에 imagegen 원본2장과 프레임 좌표·배율·접촉점 기록을 보존한다. 프롬프트는 `docs/ball-head-bump-prompt.txt`, `docs/ball-kick-transition-prompt.txt`에 있다. `tools/prepare_ball_reactions.py`가 세 캐릭터의 별도 버전 시트를 제작한다. Pillow·NumPy·SciPy는 이 제작 도구에만 필요하다. 기존 모든 PNG를 보존하고 JSON에서 새 시트로 연결한다. `head_bump`는 선택 행동이며 없는 캐릭터는 `wake_annoyed`로 대체한다. 캐릭터 ID에 따른 게임 로직 분기는 없다.

```powershell
python tools/prepare_ball_reactions.py
python verify_ball.py
python verify_all.py
.\build.ps1
```

`verify_ball.py`는 중력·반복 반동·정지·머리 관통 충돌/빗나감·양방향 유한 거리·음수 화면 좌표·30/60/144FPS를 확인한다. 실제 Qt 앱에서 세 캐릭터×64/160/400px×좌우 발차기의 고정 바닥·대기 복귀 이미지 동일성·충격 시점·비례하는 공 크기를 검사한다. 일시정지/제자리의 머리 반응, 느린 먼 공 접근, 준비 중 이동/드래그 취소와 원래 산책 중심으로 걸어 돌아오기도 확인한다. 결과와 그림은 `artifacts/ball/`에 출력한다.

## 검증 결과 (2026-10-15)

Windows11 / Python3.14.5 / Qt6.11.2에서 `verify_all.py`의13개 검사를 모두 통과했다. 기존936개 결정적 프레임과17개 원본 PNG 해시가 일치하며, Windows 실제 창 버퍼 비교도 통과했다. 세 캐릭터의 비례 공 크기·양방향 발차기·머리 반응·멀리 있는 공 접근과 취소/복귀 검사를 통과했다. 상세 로그는 `artifacts/resource-refactor/regression-results.json`, 공 검사는 `artifacts/ball/results.json`에 있다.

`dist/DeskMates.exe`를 새로 빌드했다(90,030,565bytes). 실행 파일만 별도 임시 폴더로 복사해 리베르타·제니스·세이르를 각각 실행하고 자동 종료·캐릭터 설정 저장을 확인했다. 세 실행 모두 종료 코드0이며 경고 로그가 없다. 결과는 `artifacts/ball/exe-smoke.json`에 있다.
