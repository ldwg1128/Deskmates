# 제니스 표시 선명도 개선

제니스의 초기 기본 시트는 한 프레임의 사용 영역이128×208px다. 기본 크기보다 크게 표시할 때 확대 보간의 흐림과 기존 윤곽의 계단 현상이 눈에 띈다. 같은 원본 픽셀로 확대·축소 품질을 개선하도록 `profile.render_quality="clarity-v1"`을 추가했다. 얼굴·눈·머리카락·의상·색 조합·포즈를 다시 제작하지 않으며 기존 PNG와 Canonical Reference는 그대로 사용한다.

## 처리 범위

`sprite_quality.py`는 프레임을 화면 크기로 준비할 때 투명도를 고려한 Lanczos 보간과 약한 명도 선명도 보정을 적용한다. 원본의 RGB를 새로 그리는 생성 모델이나 외부 API를 사용하지 않는다. 명도 보정은 불투명한 내부에만 적용하고 채널당 변화량을±4/255로 제한한다. 색상과 채도를 따로 바꾸지 않는다. 투명 경계는 알파를 곱한 색상으로 보간해 검은 테두리가 생기는 것을 피한다.

Qt의 기존 확대 결과와 동일한 캔버스 크기를 사용하고 알파0·32·128 기준의 포함 영역을 보존한다. 발 정렬·코너 접촉점·클릭 판정이 바뀌지 않는다. 일반 동작, 시선, 이동, 드래그·낙하·착지, 테두리 점프, 먹기·거절·배고픔, 창·수면·커서·공·간식 등 제니스의23개 행동에 적용한다. 다른 캐릭터는 기존 Qt 확대 경로를 사용한다.

캐릭터 크기를 바꾸거나 이미지를 처음 준비할 때 처리하고 결과를 최대64MiB의 LRU 캐시에 보관한다. 애니메이션의 매 틱마다 보정하지 않는다. PNG 원본을 수정하거나 고해상도 파일로 대체하지 않으므로 소스 리소스 해상도는 같다. 원본에 없는 작은 디테일을 복원하는 기능은 아니며 효과는320·400px 확대에서 더 잘 드러난다.

설정을 되돌리려면 `characters/zenith/character.json`의 `profile.render_quality` 항목을 제거한다. 저장된 게임 설정 형식과 애니메이션 시간·전환·크기는 그대로다. 게임에는 Pillow12가 추가되며 단일 EXE에 포함한다. NumPy·SciPy·이미지 생성 SDK는 실행에 필요 없다.

## 검증과 비교

```powershell
python verify_sprite_quality.py
python verify_all.py
.\build.ps1
```

`verify_sprite_quality.py`는64/160/320/400px의512개 스프라이트에 대해 캔버스 크기·알파 포함 영역·클릭 마스크가 기존과 같은지 검사한다.936개 게임 프레임의 좌표·상태·캔버스를 기존 기준과 비교하고 리베르타의 픽셀과 기존 PNG17개 해시도 확인한다.320/400px 대기 프레임의 내부 선 대비를 비교하며 Windows 실제 창 버퍼도 검사한다.

기존 픽셀 회귀 기준은 덮어쓰지 않았다. `verify_resource_regression.py`는 품질 옵션을 잠시 끈 원본 렌더러로936프레임의 완전 동일성을 검사하고, 새 검사가 보정을 켠 상태의 동작·위치 보존을 확인한다.

밝은 배경과 어두운 배경의 비교 그림은 `artifacts/zenith-clarity/comparison-400.png`, 수치와 실행 시간은 `artifacts/zenith-clarity/results.json`에 출력한다. 각 배경에서 왼쪽이 기존, 오른쪽이 개선 결과다.

## 실행 파일 확인

2026-10-15, Windows11 / Python3.14.5 / Qt6.11.2 / Pillow12.3.0에서 비교했다. `dist/DeskMates.exe`는96,553,259bytes이며, 실행 파일만 빈 임시 폴더에 복사해 제니스400px·리베르타160px·세이르160px의 표시, 설정 저장과 종료를 확인했다. 모두 종료 코드0이고 경고 로그가 없다. 상세 결과는 `artifacts/zenith-clarity/exe-smoke.json`에 있다.

전체 `verify_all.py`14개 검사도 모두 통과했다. 제니스512개 스프라이트의 크기·접촉 마스크,936개 게임 프레임의 좌표·상태·캔버스, 기존 원본 PNG17개, 공 놀이·창 상호작용·먹기·양방향 테두리·설정·외부 캐릭터와 Windows 실제 창 버퍼를 확인했다. 원본 렌더러의936프레임 픽셀 기준도 그대로 통과한다.
